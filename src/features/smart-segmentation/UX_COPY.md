# UX copy

When semantic model is unavailable:
- `Paikallinen varatila käytössä`
- `Korjaa rajaa + Lisää alue / − Poista alue -työkaluilla.`

Do not show `AI tunnisti pinnan` unless the semantic provider actually produced the accepted mask.

When semantic provider is later active:
- Loading: `Valmistellaan älykästä pintatunnistusta…`
- Encoding: `Tutkitaan kuvaa laitteellasi…`
- Result: `Pinta löytyi. Tarkista rajat ennen hyväksymistä.`
- Failure: `Pintatunnistus ei onnistunut. Voit jatkaa paikallisella työkalulla.`
