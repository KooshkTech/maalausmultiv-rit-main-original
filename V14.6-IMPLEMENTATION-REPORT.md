# Maalaus Multiväri SEO V14.6 — Implementation Report

## Implemented in this release

### 1. Service × location landing-page enrichment
The 15 existing priority landing pages for Helsinki, Espoo and Vantaa now receive service-specific and city-specific supporting copy from a single data source.

This avoids making every location page depend on the same generic paragraph while keeping the architecture maintainable.

### 2. Stronger local relevance
Each target now combines:
- the service-specific process/quality angle;
- the city-specific customer context;
- the existing city description and local facts;
- the existing service bullets, CTA and internal links.

### 3. Search-intent coverage
The priority cluster remains intentionally limited to 15 pages:
- Talon maalaus × Helsinki/Espoo/Vantaa
- Sisämaalaus × Helsinki/Espoo/Vantaa
- Julkisivumaalaus × Helsinki/Espoo/Vantaa
- Kattomaalaus × Helsinki/Espoo/Vantaa
- Ulkomaalaus × Helsinki/Espoo/Vantaa

No mass city × service expansion was introduced.

### 4. Internal-link architecture retained
Every local landing page continues to link toward:
- its parent service page;
- priority nearby service-location pages;
- the main service-area hub;
- projects;
- the cost calculator;
- the contact/quote path.

### 5. Technical SEO retained
The V14.5 technical foundation remains in place:
- canonical URLs;
- index/follow directives;
- BreadcrumbList JSON-LD;
- Service JSON-LD;
- FAQPage JSON-LD;
- ProfessionalService/Organization/WebSite schema;
- sitemap coverage;
- robots.txt sitemap declaration.

## Validation

- Sitemap contains 73 `<loc>` entries.
- All 15 priority service-location URL patterns are present in `public/sitemap.xml`.
- `robots.txt` allows crawling and points to the production sitemap.
- TypeScript source was statically reviewed after the changes.

### Build limitation
A clean dependency installation could not finish in this execution environment before timeout. The available global TypeScript compiler therefore reports missing project dependency/type packages rather than source-level errors. Before deployment, run:

```bash
npm ci --legacy-peer-deps
npm run typecheck
npm run build
npm run lint
```

## Recommended deployment order

1. Run the dependency install and validation commands above.
2. Deploy the generated production build.
3. Submit/refresh the sitemap in Google Search Console.
4. Inspect indexing for the 15 new/updated local landing pages.
5. Track impressions, clicks, queries and conversions for 30–90 days.
6. Only then expand the next service × location cluster using real Search Console evidence and project coverage.
