# Fixes Applied — 2026-08-19

Full project audit against the uploaded `maalausmultivari-updated1.zip`. Verified
structure, routes, data files, SEO files, and asset paths; cross-checked every
image path in `src/config/images.ts` against `public/images/` (all present, no
broken references); ran `tsc --noEmit` and `eslint .` (both clean).

## Fixed

1. **Warranty figure inconsistency** (`src/data/site.ts`)
   The homepage stats bar showed a 2-year warranty while every other page
   (Hero, service detail pages, cost calculator, FAQ, project descriptions)
   states "takuu jopa 5 vuotta." Corrected the stat to 5 to match the rest
   of the site's stated claim. If 2 years was actually correct and the other
   7+ mentions are wrong, let us know and it's a one-line revert.

2. **Broken social share previews** (`src/components/Seo.tsx`)
   `og:image` / `twitter:image` were rendered from a root-relative path
   (e.g. `/images/hero/about-page.webp`) on every page except the homepage
   (which hardcodes an absolute URL in `index.html`). Relative URLs aren't
   reliably resolved by link-preview crawlers (Facebook, LinkedIn, WhatsApp,
   X), so shared links for most pages showed no image. Now resolved to an
   absolute `https://maalausmultivari.fi/...` URL.

3. **69MB `images.zip` was being deployed to production** (`public/images.zip`, removed)
   Vite copies everything in `public/` into `dist/` on every build, so this
   file was shipping to `public_html/images.zip` on every deploy — publicly
   downloadable and a large amount of dead weight for HostGator's shared
   hosting. Deleted; it was not referenced anywhere in the app.

4. **Orphan duplicate image** (`public/images/cities/Kauniainen .webp`, removed)
   Unused duplicate of the correctly-referenced `kauniainen.webp` (this one
   had a capital K and a trailing space in the filename). Not referenced by
   any code path. Deleted.

5. **Duplicate documentation file** (`IMAGE-REPLACEMENT.md`, removed)
   Byte-for-byte identical to `IMAGE-REFRESH-V1.md`. Kept the latter.

## Verified as correct — not bugs

- **Sitemap "gap" in `/toimialat/*`**: `src/data/industries.ts` defines 13
  industries, but `sitemap.xml` only lists 6. This looked like a missed
  regression at first, but `IndustryPage.tsx` deliberately `Navigate`s away
  from any industry whose `status` isn't `'active-page'` — 3 are covered by
  more specific service pages (avoiding duplicate content), 3 are healthcare
  sectors flagged pending your sign-off (regulated hygiene claims), and 1 is
  intentionally too broad to be its own page. The sitemap correctly lists
  only the 6 real, published pages.
- All service (`/palvelut/:slug`) and city (`/palvelualueet/:slug`) routes
  match their sitemap entries 1:1.
- Every image key in `src/config/images.ts` resolves to a file that exists.

## Not fixed — needs your input

- **`node_modules` in the zip was built on Windows** (includes
  `@rollup/rollup-win32-x64-msvc`), which is why the project won't build on
  Linux (our sandbox, and likely any Linux CI/deploy runner) using that
  folder as-is. `node_modules` shouldn't be zipped or committed at all —
  always run `npm install` fresh on the target build machine. Removed from
  this delivered copy; run `npm install && npm run build` before deploying.
- **`HOSTGATOR-DEPLOY.md` references `.github/workflows/deploy.yml`** for
  automated deploys via GitHub Actions, but no such workflow file exists in
  the project. Either it lives outside this archive or was never created —
  let us know if you'd like one written.
